Ubuntu Linux Network Security Lab

Objective:
Learn Linux administration, network troubleshooting, and basic security scanning.

Tools Used:
- Ubuntu Linux
- Oracle VirtualBox
- Nmap
- Linux networking commands

Tasks Completed:
1. Installed and configured Ubuntu in VirtualBox.
2. Updated Linux packages using APT.
3. Identified network interfaces and IP addresses.
4. Checked the default gateway.
5. Tested network connectivity using ping.
6. Scanned localhost using Nmap.
7. Identified listening network ports.
8. Saved Nmap scan results.

Security Findings:
- Nmap target: 127.0.0.1
- Open TCP port: 631 (IPP)
- Closed TCP ports: 999
- Port 631 is commonly associated with printing services. An open port does not automatically indicate a vulnerability.

What I Learned:
I learned how to use basic Linux commands, check network configurations, test connectivity, and scan TCP ports using Nmap. I also learned how to save scan results and identify potential attack surfaces.
